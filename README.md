## ⚡ About Me

I am an **Embedded & IoT Engineer** focused on developing hardware-software systems from circuit and PCB design through firmware, device communication, data acquisition, and cloud telemetry.

My engineering work spans **embedded firmware, microcontrollers, IoT connectivity, PCB design, FPGA/VLSI, and DSP-based signal processing**. I enjoy building production-oriented systems where hardware, firmware, communication protocols, and cloud services work together as one system.

Currently working as an **IoT & Embedded Systems Engineer at Sentiantal Pvt Ltd**, where I design custom PCBs and circuits, develop firmware, build cloud-connected IoT pipelines, debug hardware and firmware, and optimize embedded systems for reliable real-time operation.

### Engineering Focus

* Embedded Systems & Firmware Development
* Embedded C / C / C++
* Microcontroller-Based Product Development
* ESP32 / STM32 / Arduino / Raspberry Pi
* RTOS & FreeRTOS
* Sensor Interfacing & Data Acquisition
* Wi-Fi / BLE Connectivity
* MQTT / HTTP Communication
* PCB & Circuit Design
* FPGA / RTL / VLSI
* Verilog / SystemVerilog
* DSP & Signal Processing
* IoT Cloud Telemetry
* Hardware & Firmware Debugging

### Open To

`Embedded Systems` `Firmware Engineering` `IoT` `Hardware Design` `PCB Design` `FPGA/VLSI` `Embedded Product Development`
